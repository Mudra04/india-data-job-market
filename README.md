# India Data Job Market Intelligence

Analysis of data analyst, BI, and data science job postings in India.

## Business Questions
1. Which cities have the most data analyst, BI, and data science openings?
2. What are the most demanded skills (SQL, Power BI, Python, Excel, Tableau...)?
3. Which skills appear together most often?
4. How do requirements and pay differ for freshers vs experienced candidates?
5. Which skills should a fresher learn first to match the most job openings?

## Tools
Python (pandas), SQLite, Power BI
